# 安装说明

本压缩包为 **Slay the Spire 2** 模组，需先安装官方 Mod 前置 **BaseLib**。

## 1. 安装 BaseLib

从 Steam 创意工坊或发行方提供的渠道安装 **【001】必装前置 / BaseLib**，并确认游戏能正常加载该前置。

## 2. 安装本模组

将 zip 解压后，把里面的 **`fat_baby` 文件夹** 整体复制到游戏 Mod 目录下，最终路径应类似：

**macOS**

```text
.../Slay the Spire 2/SlayTheSpire2.app/Contents/MacOS/mods/fat_baby/
  mod.json
  mod.dll
  mod.pck
```

**Windows**

```text
.../Steam/steamapps/common/Slay the Spire 2/mods/fat_baby/
  mod.json
  mod.dll
  mod.pck
```

（Windows 具体路径以你的 Steam 安装位置为准。）

## 3. 启动游戏

完全退出后重新打开游戏，在 Mod 列表中启用本模组。

## 故障排查

- 进游戏后 Mod 列表里没有：检查 `mods/fat_baby/` 下是否三个文件齐全，且 BaseLib 已启用。
- 更新版本：用新版本 zip 覆盖上述三个文件，重启游戏。

源码与更新日志见 GitHub 仓库的 **Releases** 页面。
