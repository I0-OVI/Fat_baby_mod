# 安装说明

本压缩包为 **Slay the Spire 2** 模组，已包含前置 **BaseLib**。

## 1. 解压

解压后会看到两个文件夹：

```text
fat_baby/
【001】必装前置/
```

## 2. 安装

将这两个文件夹整体复制到游戏 Mod 目录下，最终路径应类似：

**macOS**

```text
.../Slay the Spire 2/SlayTheSpire2.app/Contents/MacOS/mods/【001】必装前置/
.../Slay the Spire 2/SlayTheSpire2.app/Contents/MacOS/mods/fat_baby/
```

**Windows**

```text
.../Steam/steamapps/common/Slay the Spire 2/mods/【001】必装前置/
.../Steam/steamapps/common/Slay the Spire 2/mods/fat_baby/
```

（Windows 具体路径以你的 Steam 安装位置为准。）

## 3. 启动游戏

完全退出后重新打开游戏，在 Mod 列表中启用本模组。

## 故障排查

- 进游戏后 Mod 列表里没有：检查 `mods/fat_baby/` 与 `mods/【001】必装前置/` 是否都在游戏 Mod 目录下。
- 更新版本：用新版本 zip 覆盖上述三个文件，重启游戏。

源码与更新日志见 GitHub 仓库的 **Releases** 页面。
